STEP 1 — COPY FILES INTO YOUR PROJECT
═══════════════════════════════════════════════════════════════════

Copy these 4 files into the ROOT of your Django project
(same folder as manage.py):

  ✅  run.py                  ← new launcher script
  ✅  taimourian_erp.spec          ← PyInstaller configuration
  ✅  taimourian_erp_installer.iss ← Inno Setup configuration
  ✅  build.bat               ← one-click build script

Your project root should look like:

  my_project/
  ├── manage.py
  ├── run.py               ← NEW
  ├── taimourian_erp.spec       ← NEW
  ├── taimourian_erp_installer.iss  ← NEW
  ├── build.bat            ← NEW
  ├── requirements.txt
  ├── core/                (your settings folder)
  ├── accounts/
  ├── dashboard/
  ├── inventory/
  ├── sales/
  ├── templates/
  ├── staticfiles/
  └── db.sqlite3


═══════════════════════════════════════════════════════════════════
STEP 2 — EDIT settings.py  (VERY IMPORTANT)
═══════════════════════════════════════════════════════════════════

Open the file:  settings_patch.py  (provided separately)

Copy the patches into your settings.py:

  A) Replace your BASE_DIR lines with the FROZEN-aware version
  B) Replace your DATABASES section
  C) Replace your STATIC_ROOT line
  D) Replace your TEMPLATES DIRS list
  E) Add the LOGGING section

KEY CHANGES:
  • DEBUG = False
  • ALLOWED_HOSTS = ['127.0.0.1', 'localhost']
  • DATABASE path uses environment variable (so db.sqlite3 stays next to .exe)
  • STATIC_ROOT uses environment variable


═══════════════════════════════════════════════════════════════════
STEP 3 — EDIT taimourian_erp.spec (match your project)
═══════════════════════════════════════════════════════════════════

Open taimourian_erp.spec and check the CONFIGURATION section at the top:

  DJANGO_SETTINGS_MODULE = 'core.settings'
  ↑ Change 'core' to whatever your settings folder is named

  DJANGO_APPS = [ ... ]
  ↑ Make sure all your app names are listed here

  STATIC_FOLDER = 'staticfiles'
  ↑ This must match where collectstatic puts files


═══════════════════════════════════════════════════════════════════
STEP 4 — BUILD THE EXE
═══════════════════════════════════════════════════════════════════

METHOD A — Double-click (easiest):
  Double-click build.bat
  Wait 5-15 minutes
  The dist\YangEraDB\ folder will open automatically

METHOD B — Command line:
  Open Command Prompt in your project folder
  Run:
    pip install pyinstaller
    python manage.py collectstatic --noinput
    pyinstaller taimourian_erp.spec --noconfirm

After build, you will see:
  dist/
  └── YangEraDB/
      ├── YangEraDB.exe     ← the application
      ├── _internal/        ← Python + Django files
      └── ...

═══════════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════════
STEP 6 — CREATE THE INSTALLER WITH INNO SETUP
═══════════════════════════════════════════════════════════════════

1. Download Inno Setup from: https://jrsoftware.org/isdl.php
   (if not already installed)

2. Open Inno Setup Compiler

3. Click File → Open

4. Select:  taimourian_erp_installer.iss

5. IMPORTANT: Check this line at the top of the .iss file:
   #define DistFolder  "dist\YangEraDB"
   ↑ This must point to where PyInstaller created the dist folder

6. Press Ctrl+F9 (or Build → Compile)

7. Wait 2-5 minutes

8. Find your installer in:
   Output\YangEraDB_Setup_v1.0.0.exe

IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════

DATABASE:
  The db.sqlite3 file is stored NEXT TO the .exe
  (not inside the installer, so data survives app updates)
  Default location: C:\Users\...\AppData\Local\Programs\YangEraDB\

BACKUP:
  Your client's data is in db.sqlite3
  They can copy this file to backup their data

PORT:
  The app runs on port 8765
  If another app uses port 8765, edit run.py → change PORT = 8765

MULTIPLE USERS:
  This is a single-user desktop app
  Multiple people on the same PC share one browser session

UPDATE PROCESS:
  Build new installer → client installs over old version
  db.sqlite3 is NOT deleted on update (data is safe)

ERROR LOG:
  If something breaks, check:  erp_errors.log  (next to the .exe)

COMMON PROBLEMS & FIXES
═══════════════════════════════════════════════════════════════════

PROBLEM: App starts but shows "Static files not found" / CSS missing
FIX:     Make sure you ran collectstatic before PyInstaller
         Run:  python manage.py collectstatic --noinput
         Then rebuild

PROBLEM: "ModuleNotFoundError: No module named 'xyz'"
FIX:     Open taimourian_erp.spec → add 'xyz' to hidden_imports list
         Rebuild

PROBLEM: Browser opens but shows 500 error
FIX:     Set console=True in spec → rebuild → read error in black window

PROBLEM: Database not found / no tables
FIX:     The db.sqlite3 is created automatically on first run
         run.py calls migrate automatically

PROBLEM: Antivirus blocks the .exe
FIX:     This is common with PyInstaller apps
         Tell client to allow it in their antivirus
         OR: Sign the .exe with a code signing certificate

PROBLEM: App is slow on first start
FIX:     Normal — Python needs to unpack on first run
         After first start it's much faster
